## 一、项目概述

### 1.1 项目背景
龙虾AI跨境无人店系统是一个面向跨境电商卖家的智能化运营平台，通过AI智能体帮助卖家完成选品、图片设计、视频生成、Listing优化、广告投放、客服、数据复盘等全链路运营工作。

### 1.2 核心功能
- 🤖 7大AI智能体（选品、图片设计、视频生成、Listing优化、广告投放、AI客服、数据复盘）
- 📊 数据驾驶舱（实时数据监控）
- 👥 飞书用户管理（终端用户通过飞书机器人交互）
- 💰 套餐计费系统
- 📦 商品库 & 订单中心

### 1.3 系统特色
- **LangGraph智能体编排**：支持复杂状态机、多Agent协作
- **多模型路由**：统一调度豆包、DeepSeek、Kimi等模型
- **风控止损**：刚性阈值自动止损，杜绝无人值守重大损失
- **合规保障**：禁售词/禁售品类实时校验

### 2.3 技术选型理由

#### 为什么选择Python后端？

1. **LangGraph生态成熟**：Python版本的LangGraph功能更完善，支持复杂的状态机编排和多Agent协作
2. **AI生态丰富**：LangChain、LlamaIndex等AI框架对Python支持最好
3. **开发效率高**：Python语法简洁，适合快速迭代
4. **异步支持**：FastAPI原生支持async/await，性能优异

#### 为什么选择SQLite作为开发数据库？

1. **零配置**：无需安装数据库服务，开箱即用
2. **数据随项目**：数据库文件存储在项目目录，方便版本管理和迁移
3. **轻量级**：适合小型项目和开发测试
4. **易于切换**：SQLAlchemy ORM支持无缝切换到PostgreSQL

#### 为什么选择LangGraph？

1. **状态机模型**：天然适合智能体工作流编排
2. **可视化调试**：支持流程图可视化，便于理解复杂逻辑
3. **循环支持**：支持条件循环、迭代优化等复杂控制流
4. **多Agent协作**：支持多个智能体协同工作

### 4.2 认证机制

```python
# JWT Token认证
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials
from jose import jwt

security = HTTPBearer()

async def get_current_user(
    credentials: HTTPAuthorizationCredentials = Depends(security)
) -> User:
    token = credentials.credentials
    payload = jwt.decode(token, settings.JWT_SECRET, algorithms=["HS256"])
    user_id = payload.get("sub")
    return await user_service.get(user_id)
```

### 5.3 选品智能体示例

```python
from langgraph.graph import StateGraph, END
from langchain_openai import ChatOpenAI

class ProductSelectionState(TypedDict):
    query: str
    platform: str
    candidates: list[dict]
    analysis: dict
    recommendation: dict

def search_products(state: ProductSelectionState) -> ProductSelectionState:
    """搜索候选商品"""
    products = platform_api.search(state["query"], state["platform"])
    return {**state, "candidates": products[:20]}

def analyze_products(state: ProductSelectionState) -> ProductSelectionState:
    """AI分析商品"""
    llm = ChatOpenAI(model="gpt-4")
    analysis = llm.invoke(f"分析这些商品: {state['candidates']}")
    return {**state, "analysis": analysis}

def generate_recommendation(state: ProductSelectionState) -> ProductSelectionState:
    """生成推荐"""
    # 基于分析结果生成推荐
    return {**state, "recommendation": {...}}

# 构建工作流
workflow = StateGraph(ProductSelectionState)
workflow.add_node("search", search_products)
workflow.add_node("analyze", analyze_products)
workflow.add_node("recommend", generate_recommendation)

workflow.set_entry_point("search")
workflow.add_edge("search", "analyze")
workflow.add_edge("analyze", "recommend")
workflow.add_edge("recommend", END)

agent = workflow.compile()
```

### 7.3 Nginx配置

```nginx
# docker/nginx.conf
upstream frontend {
    server frontend:5000;
}

upstream backend {
    server backend:8000;
}

server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name your-domain.com;

    ssl_certificate /etc/nginx/ssl/cert.pem;
    ssl_certificate_key /etc/nginx/ssl/key.pem;
    
    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;

    # API请求转发到后端
    location /api/ {
        proxy_pass http://backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # SSE支持
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 86400s;
    }

    # WebSocket支持
    location /ws/ {
        proxy_pass http://backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }

    # 前端请求
    location / {
        proxy_pass http://frontend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
