## 一、系统架构

### 1.1 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                      飞书机器人（唯一交互入口）                    │
│    "选品 3个印尼站宠物用品 自动上架" → 触发全链路自动化            │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                     工作流编排引擎（龙虾调度中枢）                  │
│   选品 → 1688采集 → 图片处理 → 智能定价 → Listing优化 → 上架      │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌──────────────┬──────────────┬──────────────┬───────────────┐
│  7大AI智能体   │   自研轻量ERP  │  平台API集成  │   定时任务调度  │
├──────────────┼──────────────┼──────────────┼───────────────┤
│ · 选品智能体   │ · 商品管理     │ · TikTok Shop │ · 订单同步     │
│ · 图片智能体   │ · 库存管理     │ · 亚马逊SP-API│ · 库存预警     │
│ · Listing优化 │ · 采购管理     │ · TK Ads API │ · 日报生成     │
│ · 广告智能体   │ · 订单管理     └──────────────┘ └───────────────┘
│ · AI客服     │ · 物流管理
│ · 数据复盘    │ · 财务管理
│ · 视频生成    └──────────────
└──────────────┘
```

### 1.2 技术栈

| 层级 | 技术 | 版本 |

### 2.2 核心页面说明

#### 📊 控制台 (/dashboard)
- 今日数据概览：销售额、订单数、ROI
- 智能体状态：在线/离线统计
- 待处理任务：采集任务、订单履约
- 快捷入口：一键上架、订单同步

#### ⚡ 工作流编排 (/workflows) - **新增**
- 工作流模板列表：5个预定义模板
- 一键触发全链路自动化
- 执行进度实时展示
- 飞书指令说明

**工作流模板：**
| 模板 | 步骤 | 说明 |
|------|------|------|
| full_automation | 6步 | 选品→采集→图片→定价→Listing→上架 |
| image_pipeline | 2步 | 采集→图片处理 |
| single_product_publish | 5步 | 采集→图片→定价→Listing→上架 |
| order_fulfillment | 4步 | 订单同步→库存检查→采购→物流 |
| ad_campaign | 3步 | 表现分析→广告计划→提交投放 |

#### 🤖 AI智能体中心 (/ai-agents) - **合并优化**
- 概览：7大智能体状态、合规标记、风控标记
- 卡片视图：详细信息展示
- 列表视图：快速对比查看
- 快捷操作：执行、配置

**7大智能体配置：**

| 智能体 | 优先级 | 平台 | 合规 | 风控 | 核心功能 |
|--------|--------|------|------|------|----------|
| 选品智能体 | P0 | TK/亚马逊 | ✅ | - | 爆款挖掘、竞品分析、利润核算 |
| 图片智能体 | P0 | TK/亚马逊 | ✅ | - | OCR翻译、去水印、白底图 |
| Listing优化 | P1 | TK/亚马逊 | ✅ | - | 标题优化、五点描述、关键词 |
| 广告智能体 | P1 | TK Ads/亚马逊PPC | - | ✅ | 预算分配、出价建议、风控 |
| AI客服 | P1 | TK/亚马逊 | ✅ | - | 多语种回复、纠纷处理 |
| 数据复盘 | P1 | 全平台 | - | - | 销售分析、ROI计算、任务转化 |
| 视频生成 | P2 | TK东南亚 | ✅ | - | 脚本生成、AI配音、字幕 |

#### 📦 ERP系统 (/erp)

**1688采集** (/erp/collection)
- 单链接采集：输入URL → 预览 → 确认入库
- 批量采集：多URL批量处理
- 采集历史：记录查询

**商品管理** (/erp/products)
- 商品列表：内部SKU、名称、成本、状态
- 商品详情：来源信息、图片、合规状态
- 批量操作：上架、下架、删除

**库存管理** (/erp/inventory)
- 库存概览：可用库存、安全库存、预警线
- 库存流水：出入库记录
- 预警设置：安全库存阈值

**订单管理** (/erp/orders)
- 订单列表：平台订单、状态筛选
- 订单详情：商品、买家、物流信息
- 批量发货：物流单号导入

## 三、API接口

### 3.1 工作流API

```
GET  /api/v1/workflow/templates          # 获取工作流模板列表
GET  /api/v1/workflow/templates/{name}   # 获取模板详情
POST /api/v1/workflow/execute            # 异步执行工作流
POST /api/v1/workflow/execute-sync       # 同步执行工作流
POST /api/v1/workflow/full-automation    # 快捷触发全链路
GET  /api/v1/workflow/executors          # 获取执行器列表
GET  /api/v1/workflow/health             # 健康检查
```

### 3.2 TikTok Shop API

```
POST /api/v1/tiktok/products             # 创建商品
GET  /api/v1/tiktok/products/{id}        # 获取商品详情
PUT  /api/v1/tiktok/products/{id}/inventory  # 更新库存
GET  /api/v1/tiktok/orders               # 获取订单列表
GET  /api/v1/tiktok/orders/{id}          # 获取订单详情
POST /api/v1/tiktok/orders/ship          # 订单发货
GET  /api/v1/tiktok/categories           # 获取类目
POST /api/v1/tiktok/sync/orders          # 同步订单
```

### 3.3 智能体API

```
GET  /api/v1/agents                      # 获取智能体列表
GET  /api/v1/agents/{id}                 # 获取智能体详情
PUT  /api/v1/agents/{id}/config          # 更新智能体配置
POST /api/v1/agents/{id}/execute         # 执行智能体任务
GET  /api/v1/agents/{id}/tasks           # 获取任务历史
```

### 3.4 ERP API

```
# 商品管理
GET  /api/v1/erp/products                # 商品列表
POST /api/v1/erp/products                # 创建商品
PUT  /api/v1/erp/products/{id}           # 更新商品

# 订单管理
GET  /api/v1/erp/orders                  # 订单列表
POST /api/v1/erp/orders                  # 创建订单
PUT  /api/v1/erp/orders/{id}/ship        # 订单发货

# 采集
POST /api/v1/collection/collect          # 采集商品
GET  /api/v1/collection/history          # 采集历史
```

## 四、核心业务流程

### 4.1 全链路自动化流程

```
用户输入（飞书）: "选品 3个印尼站宠物用品 自动上架"
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 1. 选品智能体                                                │
│    → 分析TK印尼站宠物用品市场                                 │
│    → 输出3个爆款商品+1688链接                                 │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 2. 1688采集服务                                              │
│    → Playwright采集商品详情、图片                             │
│    → 入库ERP商品库                                           │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 3. 图片智能体                                                │
│    → OCR识别中文 → 翻译印尼语                                 │
│    → 合成新图片、合规校验                                     │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 4. 智能定价工具                                              │
│    → 成本+物流+佣金+利润                                      │
│    → 输出建议售价                                             │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 5. Listing优化智能体                                          │
│    → 生成TK短标题、标签、描述                                  │
│    → 关键词优化、合规校验                                     │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 6. 商品上架服务                                              │
│    → 调用TikTok Shop API创建商品                              │
│    → 返回上架链接                                             │
└─────────────────────────────────────────────────────────────┘
                              ↓
飞书推送: ✅ 3个商品已上架，链接：...
```

### 4.2 订单履约流程

```
定时任务（每15分钟）同步订单
        ↓
检查库存 → 库存充足 → 创建物流单 → 发货
        ↓
        库存不足 → 创建采购单 → 入库 → 发货
```

## 五、定时任务

| 任务 | 频率 | 功能 |
|------|------|------|
| 同步TikTok订单 | 每15分钟 | 拉取最新订单到ERP |
| 同步Amazon订单 | 每15分钟 | 拉取最新订单到ERP |
| 同步库存 | 每小时 | 更新各平台库存 |
| 补货预警 | 每30分钟 | 低库存飞书告警 |
| 生成日报 | 每天8:00 | 销售数据推送飞书 |
| 清理日志 | 每天凌晨2点 | 清理30天前日志 |
