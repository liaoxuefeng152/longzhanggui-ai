# 如何查看工作流执行历史

## 问题描述

在选品智能体页面点击"触发生成"后，跳转到工作流页面，但看不到启动的"单商品上架"工作流。

## 原因分析

### 之前的问题

工作流页面（`/workflows`）只显示**工作流模板列表**，不显示**工作流执行实例**。

- **工作流模板**：可用的流程定义（如"单品上架流程"、"全链路自动化"）
- **工作流执行实例**：实际执行的工作流（如"为商品A执行的单品上架流程"）

### 解决方案

在工作流页面添加了**"执行历史"**区域，用于显示所有工作流执行实例。

---

## 如何查看

### 方式1：查看工作流页面 ⭐ 推荐

1. 进入选品智能体页面
2. 点击某个商品的"触发生成"按钮
3. 自动跳转到工作流页面
4. 在页面顶部查看**"执行历史"**区域

**显示内容**：
- 工作流名称（如：单品上架流程）
- 执行状态（已完成/运行中/失败/待执行）
- 商品名称
- 执行进度（当前步骤/总步骤）
- 开始时间和完成时间
- 每个步骤的执行状态

### 方式2：刷新页面

如果执行历史没有显示，点击"刷新"按钮：

1. 在工作流页面找到"执行历史"区域
2. 点击右上角的"刷新"按钮
3. 页面会重新加载工作流执行列表
4. 显示最新的工作流记录

## 执行历史区域详解

### 区域位置

在工作流页面顶部，位于"执行进度"区域下方，"工作流模板列表"上方。

### 显示内容

每个工作流执行实例显示：

1. **工作流信息**
   - 模板名称（如：单品上架流程）
   - 执行状态（徽章显示）
   - 商品名称（如果有）

2. **执行进度**
   - 进度条（显示完成百分比）
   - 当前步骤/总步骤（如：7/7）

3. **时间信息**
   - 开始时间（如：16:15:23）
   - 完成时间（如：16:16:01）

4. **步骤状态**
   - 显示前3个步骤的执行状态
   - 每个步骤有图标指示：
     - ✅ 绿色勾选：已完成
     - ⏱️ 黄色时钟：待执行
     - ⚙️ 黄色加载中：运行中
     - ❌ 红色X：失败
   - 如果步骤超过3个，显示"+N 个步骤"

### 状态徽章

| 状态 | 样式 | 说明 |
|------|------|------|
| 已完成 | 绿色 | 所有步骤执行成功 |
| 运行中 | 黄色 | 正在执行某些步骤 |
| 失败 | 红色 | 有步骤执行失败 |
| 待执行 | 灰色 | 工作流尚未开始执行 |

## 自动刷新

### 自动刷新机制

工作流页面会在以下情况自动刷新执行历史：

1. **页面加载时**：自动加载最新的工作流执行列表
2. **点击"刷新"按钮**：手动刷新执行历史
3. **从其他页面跳转过来**：重新加载工作流列表

### 注意事项

- 执行历史按创建时间倒序排列，最新的显示在最上面
- 已完成的工作流不会自动消失，会一直保留在列表中
- 如果工作流列表为空，"执行历史"区域不会显示

## 工作流模板 vs 工作流执行

### 对比说明

| 特性 | 工作流模板 | 工作流执行实例 |
|------|-----------|--------------|
| 位置 | 工作流页面下方 | 工作流页面顶部 |
| 内容 | 流程定义 | 实际执行记录 |
| 可重复使用 | ✅ 是 | ❌ 否 |
| 显示步骤 | 固定步骤数 | 执行中的步骤状态 |
| 状态 | 总是"已配置" | 可变（pending/running/completed/failed） |

### 示例

**工作流模板**：
```
单品上架流程 (5步骤)
- 1688采集
- 图片处理
- 智能定价
- Listing优化
- 商品上架
```

**工作流执行实例**：
```
执行 #1 - 商品A
- ✅ 1688采集 (16:00:00)
- ✅ 图片处理 (16:00:30)
- ✅ 智能定价 (16:01:00)
- ✅ Listing优化 (16:01:30)
- ✅ 商品上架 (16:02:00)
状态: 已完成

执行 #2 - 商品B
- ✅ 1688采集 (16:05:00)
- ✅ 图片处理 (16:05:30)
- ⏳ 智能定价 (运行中)
状态: 运行中
```

## 故障排查

### 问题1：执行历史不显示

**检查**：
1. 确保工作流执行记录已创建（调用 `/api/debug/store/workflows`）
2. 刷新浏览器页面
3. 点击"刷新"按钮
4. 检查浏览器控制台是否有错误

### 问题2：显示旧数据

**解决**：
- 点击"刷新"按钮
- 刷新浏览器页面（F5）

### 问题3：状态显示错误

**检查**：
- 查看调试API返回的实际状态
- 确认工作流是否已完成执行
- 检查是否有步骤执行失败

## 技术实现

### 数据来源

```typescript
// 从全局存储读取工作流执行列表
const { default: store } = await import('@/lib/store');
const executions = store.getWorkflows();
```

### 数据结构

```typescript
interface WorkflowExecution {
  id: string;
  template_id: string;
  template_name: string;
  status: 'pending' | 'running' | 'completed' | 'failed';
  product_id?: string;
  product_name?: string;
  current_step: number;
  total_steps: number;
  steps: WorkflowStep[];
  started_at?: string;
  completed_at?: string;
  created_at: string;
}
```

### 排序规则

工作流执行列表按创建时间倒序排列：
```typescript
Array.from(this.workflows.values()).sort((a, b) =>
  new Date(b.created_at).getTime() - new Date(a.created_at).getTime()
);
```
