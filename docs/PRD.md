# 龙掌柜智能运营系统 - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品定位
**龙掌柜智能运营系统**是一款面向跨境电商企业的AI智能体运营平台，旨在为老板提供"智能运营助理"服务，而非"无人值守"的全自动化系统。AI辅助人工，最终决策权在老板手中。

### 1.2 核心价值主张
- **降本增效**: 7大AI智能体覆盖选品到售后的全链路运营
- **智能决策**: AI驱动的数据分析与建议
- **全链路闭环**: 从选品采集到数据复盘的完整业务闭环

### 1.3 目标用户
| 用户角色 | 使用场景 | 核心需求 |
|---------|---------|---------|
| 企业老板 | 宏观决策、异常监控 | 数据报表、异常告警、主动推送 |
| 运营总监 | 策略制定、团队管理 | 选品分析、广告优化、数据复盘 |
| 运营专员 | 日常执行、批量操作 | 图片设计、Listing优化、客服处理 |
| 系统管理员 | 系统配置、权限管理 | 模型配置、平台对接、用户管理 |

## 4. 核心功能详细说明

### 4.1 选品智能体

#### 6大核心模块

**模块1: 需求分析**
- 引导式提问：目标市场、类目偏好、预算范围、核心诉求
- 需求确认：显示当前配置的需求摘要

**模块2: 爆款挖掘**
- 选品方向推荐：基于需求分析，推荐3-5个选品方向
- 候选池展示：热门商品列表，含销量、竞争度、增长趋势

**模块3: 可行性分析**
- 利润测算：成本、物流、佣金、AD费、VAT等综合计算
- 合规校验：自动过滤禁售品类，检查平台认证要求
- 供应链匹配：评估货源稳定性和采购难度
- 风险提示：识别潜在风险点

**合规规则库**:
| 站点 | 认证要求 |
|-----|---------|
| 美区 | FDA注册、CPC证书、FCC认证 |
| 欧区 | UKCA认证、CE认证、英代信息 |
| 印尼 | BPOM注册、HALAL认证 |
| 泰国 | Thai FDA注册、TIS标准 |
| 越南 | 越南FDA注册、COA |
| 马来 | MAL注册、HALAL认证 |

**模块4: 竞品分析**
- 头部竞品挖掘：分析平台上销量Top竞品
- 差异化建议：基于竞品分析给出差异化选品建议

**模块5: 报告生成**
- 结构化报告：整合所有分析数据，生成Markdown报告
- 导出功能：支持导出本地文件

**模块6: 供应商筛选**
- 1688供应商匹配：根据选品报告推荐商品，匹配合适的1688供应商
- 供应商信息：评分、响应速度、MOQ、价格区间、发货时间、认证信息
- 一键采购：加入采购清单、复制链接、打开1688商品页
- 筛选功能：按一件代发、MOQ、排序方式筛选

## 5. 商品生命周期管理

### 5.1 状态流转

| 状态 | 说明 | 可执行操作 |
|------|------|-----------|
| draft | 草稿 | 编辑、删除 |

### 5.2 状态流转图

## 6. 客户端/管理端分离架构

### 6.1 视图切换机制

- 登录时根据用户 `role` 字段自动匹配对应菜单
- 侧边栏提供"切换视图"按钮支持手动切换
- 角色信息存储在 `localStorage.userRole`
- **权限控制**: 非管理员不能切换到管理端

### 6.2 视图差异

| 视图 | 角色 | 可见菜单 |
|-----|------|---------|
| 运营工作台 | client | 工作台、AI智能体、ERP系统、店铺管理、客服工单、数据报表、订购套餐 |
| 系统管理 | admin | 控制台、智能体配置、模型配置、平台配置、飞书机器人、任务日志、用户管理、套餐管理、系统设置 |

- 图标背景: `w-10 h-10 rounded-lg bg-{颜色}-100`
- 图标: `text-{颜色}-600`
- 数字: `text-[20px] font-semibold`
- 趋势徽章: `bg-{颜色}-50 text-{颜色}-600 border-{颜色}-200`
