## 三、启动方式

### 本地开发

```bash
# 1. 启动后端
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --reload --port 8000

# 2. 启动前端
cd ../src
pnpm install
pnpm dev
```

### Docker开发

```bash
# 一键启动
docker-compose up -d

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down
```

### 生产部署

```bash
# 配置环境变量
cp .env.example .env
vim .env

# 启动生产环境
docker-compose -f docker-compose.prod.yml up -d
```
