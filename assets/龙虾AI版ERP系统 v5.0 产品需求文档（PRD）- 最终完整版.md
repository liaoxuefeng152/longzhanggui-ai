## 二、产品定位与核心价值

### 2.1 产品定位演变

> **v1.0 定位（已废弃）**：
> "无人值守的AI跨境无人店" - 追求完全0人工值守

> **v2.0 定位（正确）**：
> **老板的"智能运营助理"** - AI驱动，人机协同

**核心差异**：

| 维度 | v1.0 定位 | v2.0 定位 |
|------|----------|----------|
| **定位** | 无人值守 | 智能助理 |
| **AI角色** | 替代人 | 辅助人 |
| **决策方式** | AI自动决策 | AI提供建议，人工决策 |
| **风险控制** | AI自主执行 | 高风险操作需人工确认 |
| **数据来源** | 追求自动采集 | 合规获取+人工录入 |
| **自动化范围** | 全链路自动化 | 可自动的自动，必须人工的人工 |

### 2.2 核心价值主张

> **飞书发指令，龙虾管全店，AI做优化，ERP做履约，图片智能处理，价格自动计算，合规无风险，老板做决策，躺赢跨境电商。**

### 2.3 与传统ERP的本质区别

| 维度           | 传统ERP（店小秘/妙手） | 龙虾AI版ERP                 |
| -------------- | ---------------------- | --------------------------- |
| **角色**       | 工具（人操作）         | 员工（AI辅助）              |
| **选品**       | 人工筛选              | AI智能选品 + 人工确认       |
| **图片**       | 手动翻译/处理         | **AI智能处理（翻译+优化）** |
| **定价**       | 定价计算器            | **智能定价工具（公式+AI）** |
| **Listing**    | 模板化，人工填写      | AI自动生成 + 人工审核       |
| **广告**       | 手动创建              | AI创建 + **人工确认高预算** |
| **客服**       | 人工回复              | AI自动回复 + **人工处理高风险** |
| **数据分析**   | 报表导出              | AI分析 + **推送关键洞察**  |
| **自动化程度** | 人操作               | **人机协同，可自动的自动** |

## 四、智能运营助理核心功能

### 4.1 飞书机器人的双重角色

| 角色 | 功能 | 触发方式 |
|------|------|---------|
| **被动响应** | 接收老板指令，执行任务 | 老板发消息 |
| **主动推送** | 定时推送日报/异常告警 | 系统自动 |

### 4.2 飞书机器人完整指令清单（P1）

#### A. 数据查询类（老板日常问的）

| 指令示例 | AI响应 |
|---------|--------|
| "今天的运营情况怎么样？" | 生成今日运营日报卡片 |
| "这周卖得最好的产品是什么？" | 数据汇总卡片（TOP 5） |
| "哪些商品库存低于10件了？" | 库存预警卡片 |
| "今天的广告花了多少钱？" | 广告消耗汇总卡片 |
| "这批订单的发货情况？" | 订单状态汇总卡片 |
| "今天的好评率是多少？" | 服务质量卡片 |
| "为什么今天的订单比昨天少了？" | 数据对比分析卡片 |
| "和上周对比，增长了多少？" | 环比分析卡片 |

#### B. 分析建议类（老板决策用的）

| 指令示例 | AI响应 |
|---------|--------|
| "帮我分析一下这个新品要不要上？" | 选品建议卡片（含利润预测、风险评估） |
| "这个产品应该定什么价格？" | 定价建议卡片（含成本明细、竞品参考） |
| "竞品在降价，我们要调整吗？" | 竞品分析卡片（含应对建议） |
| "这批广告投放效果怎么样？" | ROI分析卡片（含优化建议） |
| "帮我分析一下为什么这个商品滞销？" | 滞销分析卡片（含原因+建议） |

#### C. 文案生成类（提升效率的）

| 指令示例 | AI响应 |
|---------|--------|
| "帮我写一个催好评的消息" | 生成催好评文案 |
| "帮我写一个回复差评的话术" | 生成差评回复文案 |
| "帮我生成产品描述" | 生成英文/印尼语/泰语产品描述 |
| "帮我写一个回复客户物流咨询的话术" | 生成物流咨询回复文案 |

#### D. 报表生成类（节省时间的）

| 指令示例 | AI响应 |
|---------|--------|
| "生成今日日报" | 完整日报卡片 + 可导出 |
| "导出本周数据" | Excel报表 |
| "生成运营月报" | 完整月报卡片 |
| "生成广告效果报告" | 广告专项报告 |

#### E. 任务执行类（自动执行的）

| 指令示例 | AI响应 |
|---------|--------|
| "帮我选3款宠物用品" | 执行选品 → 返回结果卡片 |
| "优化这批商品的标题" | 执行Listing优化 → 返回结果 |
| "上架商品A" | 执行上架流程 → 返回链接 |

### 4.3 主动推送规则（P1）

#### A. 定时推送

| 推送类型 | 推送时间 | 推送内容 |
|---------|---------|---------|
| **早间日报** | 每天 09:00 | 昨日销售数据、订单量、广告消耗、库存预警 |
| **周报** | 每周一 09:00 | 本周数据汇总、环比分析、重点关注事项 |
| **月报** | 每月1日 09:00 | 上月数据汇总、月度对比、重点复盘 |

#### B. 异常告警推送（实时）

| 告警类型 | 触发条件 | 推送对象 | 紧急程度 |
|---------|---------|---------|---------|
| **库存不足** | 库存 < 安全库存 | 老板 | 🔴 高 |
| **物流异常** | 物流停滞 > 3天 | 老板+客服 | 🔴 高 |
| **差评预警** | 24h内新增 > 2个差评 | 老板+客服 | 🔴 高 |
| **广告ROI低** | ROI < 1.5 | 运营 | 🟡 中 |
| **订单取消率高** | 取消率 > 5% | 老板 | 🔴 高 |
| **断货预警** | 预计3天内断货 | 老板+采购 | 🔴 高 |
| **合规风险** | 检测到敏感词 | 老板 | 🔴 高 |
| **API异常** | 平台API调用失败 | 技术 | 🟡 中 |

#### C. 任务状态推送

| 场景 | 推送时机 |
|------|---------|
| 选品完成 | 自动推送结果卡片 |
| 上架成功 | 自动推送商品链接 |
| 广告创建 | 自动推送广告计划ID |
| 图片处理完成 | 自动推送预览链接 |

### 模块4：智能定价工具（工具模块）

| 项目       | 说明                                                         |
| ---------- | ------------------------------------------------------------ |
| **定位**   | **工具模块，非智能体**。定价是计算问题，不是创意问题，需要可解释、可调整 |
| 功能定位   | 基于成本+利润+竞品，自动计算建议售价                         |
| 计算公式   | 总成本 = 采购价+物流+佣金+广告；目标售价 = 总成本×(1+利润率)；最终价 = min(目标售价, 市场价×1.1) |
| 输入参数   | 采购价、国内物流费、头程运费、平台佣金、目标利润率、竞品价格 |
| 可配置参数 | 目标利润率、广告预算占比、竞品参考权重、价格调整范围         |
| 输出       | 建议售价 + 定价依据（成本明细、竞品参考）+ 风险提示          |
| 去向       | 回写ERP商品库                                                |

## 十一、核心备注

1. **v2.0核心原则**：定位为"老板的智能运营助理"，而非"无人值守"
2. **AI角色**：AI提供分析和建议，最终决策权在老板手中
3. **高风险操作**：广告消耗≥500元、退款≥100美元必须人工确认
4. **数据来源**：优先合规获取数据，人工录入作为补充
5. **图片智能体定位**：二合一能力，同时支持翻译模式（无货源）和优化模式（自有产品）
6. **智能定价定位**：工具模块，非智能体，公式计算+参数可配置，保证可解释性
7. **自研轻量ERP定位**：替代第三方ERP，完全自主可控
8. **飞书机器人定位**：不只是任务执行入口，更是老板的数据分析助手
9. **主动推送**：每日日报+异常告警，让老板随时掌握运营状况
10. 全程绑定"阿峰+龙虾机器人"IP
