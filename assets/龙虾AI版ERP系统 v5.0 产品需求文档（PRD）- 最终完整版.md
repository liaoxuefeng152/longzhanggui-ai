## 二、产品定位与核心价值

### 2.1 核心产品定位
基于**飞书机器人**作为前端交互入口，**龙虾机器人**作为任务调度大脑，对接**AI智能体工厂**（6个）和**智能定价工具**，以**自研轻量ERP**为数据中枢和执行中枢，打通**TK东南亚**和**亚马逊**双平台，打造**完全0人工值守的AI跨境无人店**。

### 2.2 核心价值主张
> **飞书发指令，龙虾管全店，AI做优化，ERP做履约，图片智能处理，价格自动计算，合规无风险，卖家躺赚单。**

### 2.3 与传统ERP的本质区别

| 维度           | 传统ERP（店小秘/妙手） | 龙虾AI版ERP                 |
| -------------- | ---------------------- | --------------------------- |
| **角色**       | 工具（人操作）         | 员工（AI操作）              |
| **选品**       | 人工筛选               | AI智能选品                  |
| **图片**       | 手动翻译/处理          | **AI智能处理（翻译+优化）** |
| **定价**       | 定价计算器             | **智能定价工具（公式+AI）** |
| **Listing**    | 模板化，人工填写       | AI自动优化                  |
| **广告**       | 手动创建               | AI自动投放+风控             |
| **客服**       | 人工回复               | AI自动回复                  |
| **数据分析**   | 报表导出               | AI分析+自动优化             |
| **自动化程度** | 人操作                 | AI执行                      |

#### 3.2 图片智能体（P0）- 核心升级模块

**定位**：统一处理跨境商品图片，支持**翻译模式**（无货源卖家）和**优化模式**（自有产品卖家），二合一能力。

**能力矩阵**：

| 模式         | 适用卖家     | 功能                                                 | 技术方案                       |
| ------------ | ------------ | ---------------------------------------------------- | ------------------------------ |
| **翻译模式** | 无货源卖家   | 文字识别、翻译、图片合成                             | OCR + 翻译API + OpenCV         |
| **优化模式** | 自有产品卖家 | 去水印、白底图、场景图、尺寸裁剪、美化、卖点文案叠加 | 图像处理API + 抠图API + OpenCV |

**处理流程**：

```
1688采集图片 / 用户上传图片
        ↓
判断卖家类型/模式
        ↓
┌─────────────────────┐  ┌─────────────────────┐
│ 翻译模式            │  │ 优化模式            │
├─────────────────────┤  ├─────────────────────┤
│ OCR识别中文         │  │ 去水印              │
│ 翻译成目标语言      │  │ 白底图/场景图       │
│ 图片合成            │  │ 尺寸裁剪            │
│ 字体适配            │  │ 图片美化            │
│                     │  │ 卖点文案叠加        │
└─────────────────────┘  └─────────────────────┘
        ↓
输出处理后的图片URL
        ↓
回写ERP商品库
```

**支持语言**：
- 翻译模式：印尼语、泰语、越南语、英语
- 优化模式：所有语言通用

**成本**：
- 翻译模式：约0.02元/张
- 优化模式：约0.05-0.10元/张（视处理项而定）

### 模块4：智能定价工具（工具模块）

| 项目       | 说明                                                         |
| ---------- | ------------------------------------------------------------ |
| **定位**   | **工具模块，非智能体**。定价是计算问题，不是创意问题，需要可解释、可调整 |
| 功能定位   | 基于成本+利润+竞品，自动计算建议售价                         |
| 计算公式   | 总成本 = 采购价+物流+佣金+广告；目标售价 = 总成本×(1+利润率)；最终价 = min(目标售价, 市场价×1.1) |
| 输入参数   | 采购价、国内物流费、头程运费、平台佣金、目标利润率、竞品价格 |
| 可配置参数 | 目标利润率、广告预算占比、竞品参考权重、价格调整范围         |
| 输出       | 建议售价 + 定价依据（成本明细、竞品参考）+ 风险提示          |
| 去向       | 回写ERP商品库                                                |

**为什么不是智能体？**
- 定价需要可解释性（卖家要知道为什么是这个价）
- 定价需要可调整（不同阶段不同策略）
- 公式计算比AI推理更可控、更可靠

## 六、完整业务流程示例

```
用户在飞书输入：
"帮我选3个印尼站宠物用品爆款，自动上架到TK"

系统自动执行：

【选品阶段】
1. 选品智能体调用选品工具API，分析TK印尼站宠物用品爆款
2. 筛选出3个爆款商品，提炼卖点，核算利润
3. 输出爆品清单，合规校验通过

【采集阶段】
4. 1688采集模块根据选品结果，采集商品详情、图片
5. 图片智能体识别卖家类型（无货源），自动执行翻译模式：
   - OCR识别图片中的中文
   - 翻译成印尼语
   - 合成新图片

【定价阶段】
6. 智能定价工具计算建议售价（成本+利润+竞品参考）
7. 输出定价依据：成本$18 × 1.3 = $23.4，竞品参考$28.9，最终$29.9
8. 建议售价回写ERP商品库

【内容生成阶段】
9. Listing优化智能体生成TK短标题、标签、商品描述
10. 优化后Listing回写ERP商品库

【上架阶段】
11. ERP调用TK小店API，自动创建商品

【推广阶段】
12. 广告投放智能体创建TK Ads视频加热计划，设置日预算
13. 风控引擎实时监控，超阈值自动暂停
```

## 十、核心备注

1. **v1.0核心原则**：先跑通核心链路，图片智能体作为P0核心能力
2. **图片智能体定位**：二合一能力，同时支持翻译模式（无货源）和优化模式（自有产品）
3. **智能定价定位**：工具模块，非智能体，公式计算+参数可配置，保证可解释性
4. **自研轻量ERP定位**：替代第三方ERP，完全自主可控
5. **1688采集方案**：个人开发者用Playwright，不要等官方API
6. **分阶段交付**：每阶段都有可演示成果，降低开发压力
7. 全程绑定“阿峰+龙虾机器人”IP
