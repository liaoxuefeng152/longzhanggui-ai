# 龙掌柜 - 跨境电商AI运营助手
## 原型文档（完整版 · 可直接交付UI/前端/Axure）
**版本**：V1.0
**适用**：墨刀 / Axure / Figma 高保真还原
**包含**：页面定位 + 页面视觉 + 页面交互 + 字段说明

---

# 0. 全局原型规范（所有页面统一）
- **页面定位**：PC 端后台系统，1200px 固定居中
- **视觉风格**：简洁 SaaS 风格，主色 #22C97A（绿），警示色 #F53F3F，灰色系分级
- **布局规范**：顶部导航 + 左侧菜单（MVP可隐藏）+ 右侧内容区
- **组件规范**：按钮、输入框、卡片、列表、开关、弹窗统一
- **状态规范**：加载中 → 成功 → 失败 → 告警

---

# 1. 首页 / 数据仪表盘
## 页面定位
整个产品的入口与总览页，承载**数据概览+快捷入口+动态提醒**，用户每日首次登录必看。

## 页面视觉
1. **顶部导航栏**（背景深绿 #1D2129）
   - 左侧：Logo「龙掌柜」
   - 右侧：飞书绑定状态 + 设置图标
2. **欢迎栏**（白色卡片）
   - 文字：欢迎回来！今日上新 X 个 | 广告花费 $X | ROI X.X
3. **数据卡片区**（4个等大卡片，绿色主色调）
   - 选品、上新、广告、数据 四个模块
4. **快捷操作区**（主按钮绿色）
   - 开始选品 / 一键上新 / 诊断广告 / 查看日报
5. **今日动态区**（白色面板，告警标红）
   - 列表展示最近操作与异常提醒

## 页面交互
- 点击数据卡片 → 跳转到对应功能页
- 点击快捷按钮 → 直接进入对应流程
- 点击动态告警条目 → 跳转到广告/选品详情
- 告警信息红色高亮，右上角小红点
- 页面进入时自动刷新数据，显示 1s 加载动画

---

# 2. 选品中心
## 页面定位
核心功能页，完成**关键词输入→AI分析→竞品查看→利润计算→加入上新**全流程。

## 页面视觉
1. **搜索区**
   - 关键词输入框 + 平台下拉（Shopee/Lazada/TikTok）+ 开始分析按钮
2. **AI分析结果卡片**（绿色标题）
   - 市场规模、竞争度、利润率、风险提示
3. **竞品列表**
   - 商品图、标题、价格、销量、评分、操作按钮
4. **利润计算器**（固定右侧/底部）
   - 成本输入、费用展示、售价、利润率输出
5. **操作按钮**
   - 加入草稿、加入上新队列

## 页面交互
- 输入关键词 → 点击分析 → 出现加载 → 展示结果
- 点击竞品 → 自动带入标题/图片到利润计算器
- 输入成本 → 实时计算售价与利润率
- 利润率 < 20% 标黄，< 0 标红
- 点击加入草稿 → 弹窗提示成功 → 可跳转草稿箱

---

# 3. 上新中心
## 页面定位
最高频使用的效率页面，完成**商品采集→AI处理→预览→发布**。

## 页面视觉
1. **商品采集区**
   - 1688链接输入框 + 一键采集按钮
   - 手动添加入口
2. **处理选项区**（多选框）
   - AI图片处理 / 生成Listing / 生成带货视频 / 智能定价
3. **AI处理结果区**
   - 图片预览区、Listing文案区、定价结果区
4. **底部操作栏**
   - 预览、保存草稿、发布到平台

## 页面交互
- 粘贴1688链接 → 一键采集 → 自动抓取图片/标题/属性
- 勾选处理项 → 后台异步执行 → 进度条提示
- 点击预览 → 弹窗展示平台发布效果
- 点击保存 → 存入草稿箱
- 点击发布 → 校验信息 → 成功/失败提示

---

# 4. 草稿箱
## 页面定位
商品暂存与批量管理页面，用于**编辑、再次处理、发布**。

## 页面视觉
1. **筛选栏**
   - 状态：全部/待处理/待发布
   - 平台：全部/Shopee/Lazada/TikTok
   - 时间筛选
2. **草稿列表**
   - 商品图、标题、状态、平台、创建时间、操作
3. **批量操作栏**
   - 全选、批量编辑、批量发布、批量删除

## 页面交互
- 筛选条件变化 → 列表实时刷新
- 点击编辑 → 跳转到上新中心并带入数据
- 批量选择 → 激活批量按钮
- 删除 → 二次确认弹窗
- 发布成功 → 自动移除列表并提示

---

# 5. 广告优化
## 页面定位
广告数据分析与AI诊断页面，用于**看数据、查问题、做优化**。

## 页面视觉
1. **数据概览头部**
   - 总花费、订单、ROI、ACOS、CTR、CPC
   - 时间切换：今日/7天/30天
2. **广告商品列表**
   - 商品图、广告名、花费、点击、转化、ROI、ACOS、状态
3. **AI诊断报告**（白色卡片）
   - 问题点：CTR低、ACOS高、花费暴增
4. **优化建议区**（绿色可执行按钮）
   - 加价/降价、加词/删词、调整预算、一键优化

## 页面交互
- 切换时间 → 数据自动刷新
- 点击单条广告 → 展开详细诊断
- 点击一键优化 → 确认弹窗 → 执行并提示结果
- 异常数据（ROI<1）标红高亮
- 数据加载时显示骨架屏

---

# 6. 飞书配置
## 页面定位
消息推送配置页，用于**绑定机器人、设置告警、测试推送**。

## 页面视觉
1. **绑定状态卡片**
   - 未绑定/已绑定（绿色/灰色）
   - AppID、Secret 输入框
   - 绑定/解绑按钮
2. **告警规则设置**
   - 开关列表：广告ROI低、花费暴增、库存不足、差评
3. **测试推送区**
   - 发送测试消息按钮

## 页面交互
- 输入AppID/Secret → 点击绑定 → 验证成功 → 状态变绿
- 开关可单独开启/关闭
- 点击测试 → 飞书收到测试消息
- 解绑 → 二次确认 → 清空配置

---

# 7. 核心流程跳转原型（页面流向）
## 选品流程
首页 → 开始选品 → 关键词分析 → 查看结果 → 利润计算 → 加入草稿 → 草稿箱/上新中心

## 上新流程
首页 → 一键上新 → 1688采集 → 勾选AI处理 → 生成内容 → 预览 → 发布/草稿

## 广告流程
首页 → 诊断广告 → 广告列表 → AI诊断 → 优化建议 → 一键执行 → 结果反馈

---

# 8. 弹窗原型（全局通用）
## 1）预览弹窗
- 标题：商品预览
- 内容：图片、Listing、价格、视频
- 按钮：关闭、去编辑、发布

## 2）确认弹窗
- 标题：确认操作
- 内容：确定发布/删除/优化？
- 按钮：取消、确认

## 3）结果提示弹窗
- 成功：绿色对号 + 文字
- 失败：红色叉号 + 原因
