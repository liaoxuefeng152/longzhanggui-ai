**文档版本**：V1.0
**适用阶段**：UI设计、前端研发、交互评审
**关联PRD**：龙掌柜 - 跨境电商AI运营助手 PRD（完整定稿版）V1.0

## 一、原型设计规范
### 1.1 基础规范
| 类别         | 规范要求                                                                 |
|--------------|--------------------------------------------------------------------------|
| 设计尺寸     | 桌面端：1920×1080（响应式适配1366×768及以上）|
| 设计风格     | 极简商务风，主色调：深蓝色（#165DFF）、辅助色：浅绿（#00B42A）、警示色：橙红（#F53F3F） |
| 字体         | 中文：微软雅黑/思源黑体，标题：18-24px，正文：14-16px，辅助文字：12px       |
| 交互规则     | 按钮hover态加深10%透明度，弹窗居中显示，加载态使用骨架屏/转圈加载动画       |
| 适配规则     | 核心功能模块自适应，侧边栏可折叠，列表页支持分页/筛选/排序                 |

### 1.2 通用组件库
| 组件名称     | 用途                 | 样式/交互说明                                                         |
|--------------|----------------------|----------------------------------------------------------------------|
| 主按钮       | 核心操作（发布/确认） | 蓝色背景、白色文字、圆角4px，点击态有轻微下压效果                     |
| 次按钮       | 次要操作（取消/返回） | 白色背景、蓝色边框、蓝色文字，hover态背景变浅蓝                       |
| 警示按钮     | 风险操作（删除/解除） | 橙红背景、白色文字，点击后弹出二次确认弹窗                           |
| 输入框       | 文本输入             | 灰色边框、圆角4px，聚焦态蓝色边框，有输入提示文字                     |
| 下拉选择框   | 选项选择             | 同输入框样式，展开后下拉列表最大高度300px，支持搜索筛选               |
| 列表卡片     | 商品/广告数据展示     | 白色背景、浅灰边框、圆角8px，hover态加阴影（0 2px 8px rgba(0,0,0,0.1)） |
| 弹窗         | 二次确认/表单填写     | 居中显示、蒙层半透明，弹窗内边距24px，标题加粗，底部按钮右对齐         |
| 骨架屏       | 加载中占位           | 浅灰色块，模拟内容布局，有渐变动效                                   |

#### 2.1.2 交互说明
1. 支持「密码登录」/「验证码登录」切换，切换后表单自动适配（验证码登录隐藏密码框，显示验证码输入框+获取验证码按钮）；
2. 飞书快捷登录点击后唤起飞书扫码弹窗，扫码成功后自动完成登录；
3. 登录按钮置灰规则：账号/密码（验证码）为空时置灰，输入完成后激活；
4. 错误提示：账号不存在/密码错误/验证码过期，在表单下方显示红色文字提示；
5. 记住密码：默认勾选，登录成功后保存登录态，30天内免登录。

#### 2.1.3 关联功能
- 点击「忘记密码」跳转至密码重置页（/reset-pwd）；
- 点击「立即注册」跳转至注册页（/register）；
- 登录成功后自动跳转至首页（/），并校验平台授权状态。

1. 点击「去授权」按钮后，跳转至对应平台开放平台OAuth2.0授权页面；
2. 授权成功后自动回调至本页面，对应平台状态更新为「已授权（有效期至XXXX-XX-XX）」，并显示「重新授权」「解除授权」按钮；
3. 解除授权：点击后弹出二次确认弹窗，确认后清除授权Token，状态恢复为「未授权」；
4. 授权过期：状态显示「已过期」，「重新授权」按钮高亮提醒；
5. 未授权时，首页/上新中心/广告优化模块的「发布」「同步数据」按钮置灰，并引导跳转至本页面。

4. 预览：点击后弹出全屏预览弹窗，展示最终发布效果，支持关闭/返回编辑。

#### 2.7.2 交互说明
1. 广告数据同步：
   - 未完成平台授权时，「同步数据」按钮置灰，提示「请先完成平台授权」；
   - 点击「同步数据」后，显示加载态，同步完成后更新广告列表数据；
2. 广告列表：
   - 支持按「花费」「ACOS」「ROI」排序，支持筛选「高ACOS」「低ROI」广告；
   - 点击「AI诊断」后，生成对应广告的诊断报告，展示在下方报告区；
3. 优化建议：
   - 点击「一键执行优化」后，弹出确认弹窗，确认后自动调用平台广告接口调整参数；
   - 执行成功后，弹窗提示「优化已执行」，并更新广告数据；
4. 异常告警：列表中高风险广告（如ROI<1）标红显示，并有「告警」标签。

## 三、核心交互流程原型
### 3.1 完整上新流程
```
登录页 → 平台授权页（未授权时引导）→ 首页 → 上新中心
→ 1688链接采集 → 勾选AI处理项 → 预览编辑
→ 存草稿 / 发布（校验授权）→ 发布成功/失败提示
```

### 3.2 完整选品-上新闭环流程
```
选品中心 → 输入筛选条件 → 查看选品结果 → 点击「加入上新队列」
→ 上新中心（自动加载选品商品信息）→ AI处理 → 发布/存草稿
```

### 3.3 广告优化流程
```
广告优化页 → 同步广告数据（校验授权）→ 选择广告 → AI诊断
→ 查看优化建议 → 一键执行优化 → 效果追踪
```
