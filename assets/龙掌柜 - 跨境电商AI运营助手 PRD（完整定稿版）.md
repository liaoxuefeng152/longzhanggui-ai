# 龙掌柜 - 跨境电商AI运营助手 PRD（完整定稿版）
**文档版本**：V1.0
**适用阶段**：MVP 研发、产品评审、团队协作
**可直接复制使用**

---

## 1. 产品定位
### 1.1 一句话介绍
用 AI 实现选品、上新、广告优化全链路自动化，让跨境电商个人卖家与小团队效率提升 5–10 倍。

### 1.2 目标用户
- 个人跨境电商卖家
- 1–5 人小团队
- 无专业美工、运营、投手的卖家

### 1.3 使用场景
单人即可完成全流程运营：快速选品、一键上新、智能广告优化、实时消息告警，一站式闭环操作。

---

## 2. 核心价值
| 痛点           | 现状                          | 产品解决方案                                  |
| -------------- | ----------------------------- | --------------------------------------------- |
| 不知道卖什么   | 靠经验选品，失败率高          | AI 分析市场数据，输出可量化选品建议与风险评估 |
| 上新效率低     | 图片+Listing 需耗时半天至一天 | 一键生成图片、文案、视频，支持批量处理        |
| 广告投放亏     | 投流盲目、优化滞后            | AI 诊断广告数据，给出可直接执行的优化方案     |
| 数据分散难管理 | 多平台数据需手动汇总          | 飞书助手推送日报/异常告警，支持自然语言查询   |

---

## 3. 功能结构
### 3.1 智能选品（解决：卖什么）
**入口**：首页 → 开始选品

| 功能       | 说明                                               | 优先级 |
| ---------- | -------------------------------------------------- | ------ |
| 市场分析   | 输入类目/关键词，AI 分析市场规模、竞争度、利润空间 | P0     |
| 竞品挖掘   | 抓取热销竞品，展示价格、评分、销量、核心卖点       | P0     |
| 利润计算   | 输入成本，自动计算售价、利润率、包含佣金与物流费   | P0     |
| 选品报告   | 生成结构化建议，含竞争风险、利润预测、操作指引     | P1     |
| 供应链匹配 | 自动匹配 1688 供应商，展示价格、起订量、店铺评分   | P1     |
| 竞品监控   | 监控竞品价格/评分异动，异常触发告警                | P2     |

**用户流程**
```
输入类目/关键词 → AI 数据分析 → 查看选品报告 → 确认商品 → 加入上新队列 → 匹配供应商
```

**数据来源**
Shopee、Lazada、TikTok Shop 公开数据；1688 供应链数据。

---

### 3.2 快速上新（解决：上新慢）
**入口**：首页 → 开始上新

**核心流程**
```
1688 链接采集 / 手动添加
→ 勾选处理项
  □ AI 图片处理（白底/翻译/优化）
  □ Listing 生成（标题/描述/关键词）
  □ 15 秒带货视频生成
  □ 智能定价
→ 预览编辑
→ 发布至平台 / 存入草稿
```

| 功能         | 说明                                     | 优先级 |
| ------------ | ---------------------------------------- | ------ |
| 商品采集     | 1688 链接一键采集，支持手动录入信息      | P0     |
| 图片处理     | AI 抠图、白底、去水印、多语言图文翻译    | P0     |
| Listing 生成 | 多语言标题、五点描述、详情、关键词       | P0     |
| 带货视频     | 图片生成 15 秒短视频，配音+字幕+背景音乐 | P1     |
| 智能定价     | 按成本、竞品、平台规则计算最优售价       | P0     |
| 草稿箱       | 暂存未发布商品，支持筛选、批量编辑       | P0     |
| 批量上新     | 一次处理多个商品，提升效率               | P1     |
| 多平台发布   | 支持 Shopee/Lazada/TikTok Shop           | P1     |

---

### 3.3 广告优化（解决：广告烧钱）
**入口**：首页 → 广告优化

| 功能         | 说明                                     | 优先级 |
| ------------ | ---------------------------------------- | ------ |
| 广告数据同步 | 拉取花费、点击、转化、ROI、ACOS 等数据   | P0     |
| AI 诊断报告  | 自动分析问题：CTR 低、ACOS 高、转化差等  | P0     |
| 优化建议     | 给出可执行动作：加词、减词、调价、调预算 | P0     |
| 一键执行优化 | 支持直接在系统内调整广告参数             | P1     |
| 异常告警     | ROI 过低、花费暴增、异常消耗实时提醒     | P0     |
| 广告周报     | 每周自动生成数据汇总与优化总结           | P1     |

**用户流程**
```
广告数据同步 → 查看广告列表 → AI 诊断 → 查看建议 → 执行优化 → 追踪效果
```

---

### 3.4 飞书助手（消息推送与查询）
**入口**：飞书机器人绑定

| 功能     | 说明                                        | 优先级 |
| -------- | ------------------------------------------- | ------ |
| 异常告警 | 库存不足、广告亏损、差评、数据异常推送      | P0     |
| 运营日报 | 每日推送订单、广告、上新、销售额汇总        | P1     |
| 快捷查询 | 文字/语音查询：今日出单、广告花费、选品建议 | P1     |
| 智能咨询 | 自然语言问品、问类目、问趋势，AI 回复       | P2     |

## 6. 不做的功能（边界明确）
| 模块       | 不做原因                     |
| ---------- | ---------------------------- |
| 库存管理   | 个人卖家商品少，平台自带足够 |
| 采购管理   | 直接在 1688 下单即可         |
| 物流追踪   | 平台原生功能已满足           |
| 订单管理   | 依赖平台后台，不重复开发     |
| 财务管理   | 逻辑复杂，MVP 暂不支持       |
| 多店铺管理 | 目标用户仅 1–2 个店铺        |
| 团队协作   | 小团队无需权限与协作         |
