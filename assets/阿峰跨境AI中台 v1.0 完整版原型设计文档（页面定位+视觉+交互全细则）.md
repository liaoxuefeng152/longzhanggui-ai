# 一、全局通用设计规范

## 1.1 视觉统一规范

### 配色体系

| 颜色类型 | 色值 | 用途 |
|---------|------|------|
| 主色 | #165DFF（深海蓝） | 凸显跨境科技感，主要按钮、重点强调 |
| 成功色 | #00B42A | 成功状态、正向指标增长 |
| 警示色 | #FF7D00 | 预警提示、需要关注 |
| 错误色 | #F53F3F | 错误提示、负向指标、紧急告警 |
| 辅助色 | #86909C（中性灰） | 次要文字、边框线、辅助信息 |
| 背景色 | #F7F8FA（浅灰） | 页面背景、卡片背景 |
| 智能助理色 | #7C3AED（紫罗兰） | 智能分析、AI推荐相关内容 |

### 字体规范

- **后台端**：思源黑体（优先）、系统默认字体降级
- **飞书端**：沿用飞书原生字体，保证适配性
- **标题**：16-20px，加粗
- **正文**：14px
- **辅助文字**：12px
- **数据卡片数值**：24-32px，加粗

### 布局规范

| 端 | 布局类型 | 说明 |
|----|---------|------|
| 后台端 | 固定左侧导航+顶部状态栏+右侧内容区 | 面包屑导航常驻 |
| 飞书端 | 纯消息卡片+快捷按钮 | 无冗余布局，消息即界面 |

### 图标规范

- 统一使用线性图标，简洁易懂
- 功能图标配文字说明
- 禁用复杂图标
- 新增：智能分析相关使用 ⚡ 闪电图标

## 1.2 交互统一规范

### 操作反馈

| 状态 | 视觉表现 | 说明 |
|------|---------|------|
| 悬浮态 | 背景色加深5%、轻微上移 | 鼠标悬停 |
| 点击态 | 背景色加深10%、轻微下沉 | 鼠标按下 |
| 禁用态 | 灰色背景、不可点击 | 无权限或未填写 |
| 加载态 | 按钮显示loading动画 | 请求中 |

### 状态流转（全局任务状态统一）

| 状态 | 图标 | 颜色 | 说明 |
|------|------|------|------|
| 待执行 | ⏳ | 灰色 | 等待处理 |
| 执行中 | 🔄 | 蓝色 | 正在处理 |
| 已完成 | ✅ | 绿色 | 成功完成 |
| 异常 | ⚠️ | 橙色 | 执行出错 |
| 风控拦截 | 🛡️ | 红色 | 被风控阻止 |
| 已取消 | ❌ | 灰色 | 人工取消 |
| 待确认 | 🔔 | 紫色 | **新增：需人工确认** |
| 已推送 | 📤 | 蓝色 | **新增：已发送飞书** |

### 便捷操作

- 后台页支持批量操作、一键重置、快速搜索
- 飞书端支持快捷指令、一键跳转、重复操作
- **新增**：支持老板日常问询的自然语言输入

### 权限拦截

- 无权限按钮置灰
- 点击弹出"无操作权限，请联系超级管理员"提示
- **新增**：高风险操作弹出"需管理员确认"提示

# 二、管理员后台全页面详情

## 页面1：管理员登录页

### ✅ 页面定位

中台后台唯一入口，严格权限校验，杜绝非管理员登录，保障系统数据安全

### 🎨 视觉布局

- **整体**：居中布局，背景为浅渐变蓝色，无冗余元素
- **顶部**：中台LOGO+产品名称（阿峰跨境AI中台）+版本号v2.0
- **中间**：登录表单卡片（白色背景、圆角8px、轻微阴影）
  - 账号输入框
  - 密码输入框
  - 验证码框
  - 登录按钮
- **底部**：版权信息、管理员专属入口提示、忘记密码入口

### 🖱️ 交互逻辑

| 场景 | 交互表现 |
|------|---------|
| 输入为空 | 登录按钮置灰不可点击 |
| 输入完整 | 按钮高亮可点击 |
| 账号/密码错误 | 红色toast提示"账号或密码错误，剩余X次尝试机会"，连续5次错误锁定账号10分钟 |
| 验证码错误 | 自动刷新验证码，清空验证码输入框 |
| 登录成功 | 跳转至控制台首页，记录登录日志（IP、时间、设备） |
| 登录失败 | 保留账号输入，清空密码、验证码 |

| 交互 | 行为 |
|------|------|

## 页面3：模型路由管理页

### ✅ 页面定位

AI模型统一调度中心，管理私有模型+公有模型，实现负载均衡、故障切换、成本管控，保证智能体稳定运行

### 🎨 视觉布局

- **顶部**：页面标题 + 搜索框（按模型名称/类型搜索） + 新增模型按钮
- **筛选区**：模型类型（本地/公有）、运行状态（在线/离线/异常）筛选器
- **内容区**：模型列表表格（固定表头，支持排序）
  - 列字段：模型ID、模型名称、类型、接入平台、运行状态、QPS上限、调用次数、剩余额度、负载率、操作
- **弹窗**：新增/编辑模型弹窗（表单：名称、类型、API地址、密钥、QPS阈值、负载上限）

### 🖱️ 交互逻辑

| 交互 | 行为 |
|------|------|
| 列表操作 | 每行包含编辑、启用/禁用、删除、查看日志按钮 |
| 删除模型 | 需二次确认，已绑定智能体的模型禁止删除 |
| 负载预警 | 负载率≥80%标红高亮，点击可查看负载详情 |
| 故障切换 | 模型离线时，自动切换备用模型 |
| 筛选搜索 | 输入关键词实时过滤，支持重置筛选条件 |

| **对话能力** | 单轮任务 | 多轮对话，支持追问 |
