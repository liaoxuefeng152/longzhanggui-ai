## 二、产品定位与核心目标
### 2.1 核心产品定位
基于**飞书机器人**作为前端交互入口，**龙虾机器人**作为任务调度大脑，对接**AI智能体工厂**（7个优化后AI智能体），以**ERP系统**为数据中枢和执行中枢，打通**TK东南亚**和**亚马逊**双平台，打造**合规、风控、可落地的0人工值守AI跨境无人店**，核心解决跨境运营“人工成本高、合规风险大、异常处理不及时”痛点。

### 2.2 核心业务目标
- **技术闭环**：飞书→龙虾→AI智能体→ERP→多平台全链路打通，新增**合规校验、风控触发、异常处理**自动化链路
- **功能闭环**：覆盖选品→内容生成→Listing优化→广告投放→订单履约→客服→复盘，所有环节实现**合规落地、风险可控、异常自处理**
- **跨平台能力**：同时支持TK东南亚和亚马逊，架构可扩展至Shopee/Lazada，各环节适配平台差异化规则
- **商业落地**：支撑单人/小团队实现7×24小时无人运营，**杜绝合规违规、广告亏损、订单履约失败**核心风险
- **数据闭环**：复盘结果自动转化为优化任务，实现“运营→分析→优化”的自动化循环

### 2.3 核心价值主张
> **飞书发指令，龙虾管全店，AI做执行，ERP做履约，合规无风险，卖家躺赚单**

### 模块3：AI智能体工厂（7个核心优化智能体）
#### 3.1 智能选品智能体（核心优化：合规+供应链校验）
| 项目     | 说明                                                         | 核心优化点                                                   |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 数据来源 | 选品工具API（Jungle Scout/Helium 10/TK爆款工具）+ ERP库存/采购数据 + 平台合规规则库 | 新增ERP和合规规则库数据源                                    |
| 核心能力 | 爆款挖掘、竞品分析、利润核算、卖点提炼                       | 1. **平台合规校验**：自动过滤TK/亚马逊禁售品类、需类目审核未开放的商品；2. **供应链匹配校验**：筛选采购周期≤7天、库存成本≤预估售价30%的商品；3. 剔除合规/供应链不匹配的商品 |
| 输出     | 爆品清单（含预估利润、卖点）                                 | 新增字段：合规状态、供应链匹配度、采购周期、库存成本占比     |
| 去向     | 回写ERP（待采购）+ 触发内容生成智能体                        | 仅回写**合规+供应链匹配**的商品至ERP，剔除不合格商品         |
| 异常处理 | -                                                            | 合规/供应链不匹配商品自动过滤，无有效结果时推送飞书告警      |

#### 3.2 图片设计智能体（核心优化：合规校验）

| 去向                         | 回写ERP → ERP上架到对应平台                                  | 仅回写/上架合规Listing，仍违规则推送飞书告警                 |
| **合规检测规则（优化版）**： |                                                              |                                                              |
| 检测项                       | 规则                                                         |                                                              |

#### 3.5 广告投放智能体（核心优化：全维度风控引擎）
| 项目     | 说明                                        | 核心优化点（新增广告风控引擎）                               |
| -------- | ------------------------------------------- | ------------------------------------------------------------ |
| 数据来源 | ERP（订单ROI、历史广告数据）+ 平台广告API   | 无                                                           |
| 核心能力 | 预算分配、出价建议、关键词挖掘              | 1. **预算风控**：单店铺单日广告消耗≤预设阈值（固化值：500元/天），超阈值则暂停所有广告；<br>2. **ROI风控**：单商品广告ROI＜1:1时自动暂停该商品广告；<br>3. **点击成本风控**：TK Ads单次点击＞0.5美元、亚马逊PPC单次点击＞1美元时自动降低出价20%；<br>4. 风控规则执行中每小时校验1次，触发后推送飞书告警 |
| 平台适配 | TK Ads（视频加热）、亚马逊PPC（关键词竞价） | 无                                                           |

#### 3.6 多语种AI客服智能体（核心优化：纠纷处理+话术合规）

## 十、核心备注（优化版核心原则）
1. **v1.0核心原则**：**先闭环、再优化，先合规、再运营**，所有优化仅聚焦核心功能，无任何体验类、可视化类改动，确保7天单人可落地；
2. **ERP核心定位**：ERP是**数据中枢+执行中枢+异常处理中枢**，所有平台操作、数据流转均通过ERP，无直接跨平台调用，保障系统稳定性；
3. **合规/风控刚性原则**：所有环节**合规校验为前置条件**，合规不通过则禁止执行后续操作；所有核心风险点**风控阈值为刚性值**，触发后自动止损，杜绝无人值守下的重大损失；
4. **数据闭环原则**：复盘结果必须自动转化为优化任务，实现“运营→分析→优化”的自动化循环，无人工干预也能持续优化运营效果；
5. **操作可追溯原则**：全链路操作日志完整记录，所有动作可查询、可追溯，便于问题排查和责任界定；
6. 所有智能体通过API调用，龙虾机器人不做冗余开发，全程绑定“阿峰+龙虾机器人”IP，强化产品辨识度。
