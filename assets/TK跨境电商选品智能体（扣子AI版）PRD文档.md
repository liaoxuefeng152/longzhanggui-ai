# 二、产品概述

## 2.1 产品定位

基于扣子AI的智能体、插件、知识库能力，打造一款轻量化、低成本、易上手的TK跨境选品辅助工具，聚焦中小卖家“选品难、判断难、落地难”的核心痛点，无需复杂操作，通过对话交互即可完成选品需求分析、爆款挖掘、可行性测算、竞品分析及报告生成，替代人工手动整合数据的繁琐流程，提升选品效率和决策准确性。

## 2.2 核心价值

- 高效性：自动抓取、整合TK爆款数据、供应链信息，减少80%手动数据整理时间；

- 实用性：聚焦中小卖家预算和需求，提供轻量化功能，无需专业数据分析能力即可使用；

- 准确性：结合AI算法+合规知识库，规避侵权、合规风险，提升选品成功率；

- 落地性：输出结构化选品报告，包含具体执行建议，直接指导卖家选品和运营。

## 2.3 产品边界

- 核心边界：仅聚焦TK跨境电商选品全流程辅助，不涉及店铺运营、订单管理、物流跟踪等非选品相关功能；

- 数据边界：优先对接合规第三方工具API、公开数据及用户上传数据，不做无授权TK平台数据爬取，规避合规风险；

- 决策边界：仅提供选品分析和建议，不替代用户最终决策，需结合用户行业经验补充判断。

# 三、用户画像与核心痛点

## 3.1 核心用户画像

|用户类型|特征描述|核心需求|
|---|---|---|
|个人卖家（新手）|刚入局TK跨境，预算有限（5000-20000元），无选品经验，不熟悉平台规则和供应链|快速找到低竞争、高利润、易操作的选品方向，规避风险，获取简单可落地的建议|
|小团队选品专员|有基础选品经验，需批量筛选爆款，手动整合数据耗时久，需提升选品效率|快速挖掘爆款候选品，自动完成利润测算、合规校验，生成结构化报告，节省时间|
|中小卖家（进阶）|有稳定店铺，需拓展新品类，关注竞品玩法，追求差异化选品|竞品拆解、差异化建议，供应链匹配，精准判断新品潜力，拓展选品边界|
## 3.2 核心痛点

1. 选品方向模糊：不知道当前TK平台哪些类目/商品有潜力，盲目选品导致滞销；

2. 数据整合繁琐：需手动从TK平台、第三方工具、供应链平台抓取数据，耗时耗力，易出错；

3. 利润与风险难判断：不会精准测算毛利、回本周期，易忽略侵权、合规、物流等风险；

4. 竞品玩法难追踪：无法快速拆解头部竞品的运营策略，难以做出差异化选品；

5. 工具门槛高：现有选品工具要么价格昂贵，要么操作复杂，不适合中小卖家使用。

# 四、核心功能模块设计（基于扣子AI开发）

整体交互逻辑：用户进入智能体→引导式提问（明确需求）→数据抓取与分析→输出选品建议→生成选品报告，全流程以对话交互为主，降低操作门槛。

## 4.1 模块1：选品需求分析（入口层）

### 4.1.1 功能描述

通过引导式对话，捕捉用户选品偏好和核心需求，缩小选品范围，生成初步选品方向清单，为后续爆款挖掘和分析提供基础。

### 4.1.2 核心功能点

- 引导式提问：智能体主动发起提问，引导用户输入目标市场、类目偏好、成本预算、核心诉求（高利润/低竞争/快周转）、是否有规避类目；

- 需求解析：AI自动解析用户输入的信息，提取关键标签（如“美区+家居+拿货价≤5美元+低竞争”）；

- 方向输出：基于用户需求，结合预设的类目-市场匹配库，生成3-5个初步选品方向，每个方向附带简单说明（如“美区家居类目，低竞争方向：厨房收纳小工具，原因：近30天搜索增长60%，在售卖家少”）。

### 4.1.3 扣子AI落地方式

- 对话流程设计：用扣子AI“对话流程”功能，配置引导式提问话术，设置分支逻辑（如用户未明确预算，可进一步追问“您的拿货价预算大概在哪个区间？”）；

- 标签库搭建：手动上传“类目-市场-竞争度”标签库到扣子知识库，AI通过关键词匹配，生成选品方向；

- 对话记忆：开启扣子“对话记忆”功能，记住用户输入的需求信息，后续功能无需重复提问。

### 4.1.4 交互原型（文字描述）

智能体欢迎语：“您好！我是TK跨境选品智能体，帮您快速找到高潜力选品~ 请告诉我您的目标市场（如美区/欧区/东南亚）？”

用户输入后，智能体继续提问，直至收集完所有核心信息，输出：“感谢您的输入，结合您的需求（美区+家居+拿货价≤5美元+低竞争），为您推荐3个选品方向：1. 厨房收纳小工具... 2. 宠物喂食器配件... 3. 浴室置物小物件... 请问您想优先分析哪个方向，或需要我直接挖掘该方向的爆款候选品？”

## 4.2 模块2：爆款数据挖掘（核心数据层）

### 4.2.1 功能描述

基于用户确定的选品方向，抓取TK平台热门数据、趋势数据，分析商品潜力，过滤高风险商品，生成“爆款候选池”，为用户提供精准的选品候选对象。

### 4.2.2 核心功能点

- TK热门商品抓取：抓取目标市场近7天/30天，点赞≥10万、评论≥1000、分享≥5000的商品视频，提取商品名称、核心卖点、售价、销量预估、所属类目；

- 趋势洞察：对接TK Trends/Google Trends，展示目标类目/商品的搜索热度、增长趋势（如“便携榨汁杯”近30天搜索增长80%）、季节属性（是否为应季商品）；

- 竞争度分析：计算目标类目在售卖家数、头部卖家市场占比、商品价格区间，判断类目红海/蓝海（蓝海标准：在售卖家≤500，头部占比≤30%）；

- 候选池筛选：过滤品牌垄断（头部3家卖家占比≥60%）、侵权风险高（有明显品牌logo、专利产品）、物流难度大（超大/超重）的商品，输出10-20个爆款候选品，标注推荐指数（1-5星）。

### 4.2.3 扣子AI落地方式

- 插件对接：用扣子AI“插件开发”功能，对接合规第三方选品工具API（如蝉妈妈TK版、TK Spy），获取热门商品数据、趋势数据（优先使用免费试用额度，降低成本）；

- 网页抓取：若无API权限，用扣子“网页抓取”功能，爬取TK公开的热门商品页面、趋势页面（注意合规，仅抓取公开可访问数据，不破解平台限制）；

- AI数据清洗：编写简单Python函数（通过扣子“函数调用”功能实现），对抓取的数据进行过滤、去重、标注，生成爆款候选池。

### 4.2.4 输出格式

爆款候选池（表格形式，可查看详情/筛选）：

|商品名称|核心卖点|售价（美元）|预估销量（月）|竞争度|推荐指数|操作|
|---|---|---|---|---|---|---|
|厨房硅胶收纳夹|食品级硅胶、可重复使用、多功能|9.99|5000+|蓝海|5星|查看详情/可行性分析|
## 4.3 模块3：选品可行性分析（决策层）

### 4.3.1 功能描述

对爆款候选池中的单个/多个商品，进行利润测算、合规校验、供应链匹配、风险提示，给出明确的“可做/不做”建议，帮助用户判断商品可行性。

### 4.3.2 核心功能点

1. 利润测算：
        

    - 用户输入关键参数（拿货价、物流费、平台佣金、广告费、VAT税率），AI自动计算毛利、毛利率、回本周期；

    - 预设常用参数模板（如美区平台佣金12%、VAT税率7%，东南亚平台佣金8%、无VAT），用户可直接选用，也可手动修改；

    - 输出利润测算明细，标注“高利润”（毛利率≥30%）、“中等利润”（毛利率15%-30%）、“低利润”（毛利率<15%）。

2. 合规校验：
        

    - AI检索扣子知识库中的TK平台规则、目标市场法规（如美区FDA、欧区CE、东南亚当地合规要求）；

    - 判断商品是否侵权（专利、商标、版权）、是否需要相关认证（如美妆类需FDA认证），输出“合规”“需补充认证”“侵权风险高（不建议选）”的结论。

3. 供应链匹配：


    - 对接1688/Alibaba插件，检索同款商品的供应商信息（名称、拿货价、起订量、发货时间）；

    - 标注供应链稳定性（如“起订量100件，拿货价3美元，支持一件代发，稳定性高”），帮助用户判断供货能力。

4. 风险提示：
        

    - 标注商品潜在风险：退货率高（如服装、鞋类）、物流易碎（如玻璃制品）、季节属性强（如圣诞礼品）、平台管控严（如电子烟、医疗用品）；

    - 给出风险规避建议（如“服装类建议先小批量测试，控制退货风险”）。

5. 可行性结论：综合以上分析，给出“强烈推荐”“谨慎推荐”“不推荐”的结论及核心理由。

### 4.3.3 扣子AI落地方式

- 利润测算：用扣子“函数调用”功能，编写Python利润测算函数，配置参数输入框，用户输入后自动计算并输出结果；

- 合规校验：搭建“合规知识库”，上传TK平台规则、各国合规法规文档，用扣子“知识库问答”功能，训练AI通过语义检索判断商品合规性；

- 供应链匹配：对接1688公开插件，通过扣子“插件调用”功能，一键查询同款商品供应链信息；

- 风险提示：预设风险标签库（如“退货率高”“易碎”），AI根据商品类目自动匹配风险标签，输出规避建议。

## 4.4 模块4：竞品分析（优化层）

### 4.4.1 功能描述

针对用户选定的目标商品，抓取TK平台头部竞品（销量Top3）的运营数据，拆解其玩法，给出差异化选品和运营建议，帮助用户打造核心竞争力。

### 4.4.2 核心功能点

- 竞品抓取：抓取目标商品的头部3家竞品（销量最高、好评率最高）的TK视频（封面、文案、背景音乐、播放量）、商品详情页（卖点、定价、评价）、直播话术（若有）；

- 竞品拆解：AI分析竞品的核心卖点、定价策略、视频创意、用户评价痛点（如“竞品评价中多反馈‘续航短’”）；

- 差异化建议：
        

    - 卖点优化：结合竞品痛点，给出差异化卖点（如竞品强调“耐用”，建议突出“便携+耐用”）；

    - 定价策略：给出合理定价建议（如略低于竞品5%，或持平但增加附加价值）；

    - 视频创意：参考竞品爆款视频，给出差异化创意（如竞品做开箱，建议做场景化使用演示）；

    - 评价优化：针对竞品用户痛点，建议在商品详情页提前规避（如“标注‘续航长达10小时’，解决用户续航顾虑”）。

### 4.4.3 扣子AI落地方式

- 竞品数据抓取：用扣子“网页抓取”功能，爬取竞品的TK视频页面、商品详情页，提取文本、图片信息；

- AI分析：用扣子“文本/图片分析”功能，拆解竞品文案、视频内容，提取核心卖点和用户痛点；

- 建议生成：基于竞品分析结果，结合选品方向，用扣子AI自然语言生成功能，输出差异化建议。

## 4.5 模块5：选品报告生成（输出层）

### 4.5.1 功能描述

整合前面所有模块的分析数据，自动生成结构化选品报告，支持查看、下载（Markdown/Word格式），方便用户存档、决策或团队同步。

### 4.5.2 核心功能点

- 报告自动生成：用户完成选品分析后，AI自动填充所有数据，生成标准化选品报告，无需手动编辑；

- 报告内容：包含用户需求概述、选品方向分析、爆款候选池、单个商品可行性分析、竞品分析、差异化建议、执行建议（优先测试哪个品、定价区间、推广方式）；

- 报告下载：支持生成Markdown/Word格式，提供下载链接，方便用户保存和分享；

- 报告自定义：支持用户选择报告重点（如仅生成“可行性分析+执行建议”），精简报告内容。

### 4.5.3 扣子AI落地方式

- 报告模板配置：在扣子AI中配置标准化报告模板（Markdown/Word格式），设置数据填充节点；

- 数据自动填充：通过扣子“函数调用”功能，将前面模块的分析数据（爆款数据、利润测算、竞品分析）自动填充到模板对应节点；

- 下载功能：对接扣子“文件生成”插件，生成报告文件并提供下载链接。

# 五、非功能需求

## 5.1 性能需求

- 响应速度：引导式提问响应时间≤1秒，数据抓取与分析响应时间≤10秒（单商品分析），报告生成时间≤15秒；

- 稳定性：连续使用1小时无崩溃，数据抓取成功率≥90%（若第三方API故障，给出明确提示）；

- 兼容性：支持电脑端、手机端扣子AI平台访问，无需额外下载APP。

## 5.2 合规需求

- 数据合规：仅抓取TK平台、第三方工具公开可访问的数据，不涉及用户隐私、平台内部数据，规避爬取违规风险；

- 内容合规：生成的选品建议、报告不包含侵权、违规商品推荐，严格遵循TK平台规则和目标市场法规；

- 版权合规：使用的插件、数据工具需具备合法授权，不使用盗版工具或无授权数据。

## 5.3 易用性需求

- 操作门槛：全程对话交互，无需专业技能，新手用户可快速上手，引导式提问清晰易懂；

- 反馈清晰：数据抓取、分析过程中，给出明确提示（如“正在抓取TK热门数据，请稍候...”），异常情况（如API故障）给出具体解决方案；

- 帮助引导：内置简单帮助话术，用户提问“怎么测算利润”“怎么下载报告”时，自动给出操作指引。

# 七、避坑要点与注意事项

- 数据合规优先：严禁无授权爬取TK平台数据，初期优先使用第三方合规工具API，避免平台封号或法律风险；

- 功能轻量化：避免堆砌功能，优先保障“爆款挖掘+利润测算”核心功能的稳定性，再逐步迭代其他功能；

- AI准确性调优：定期更新知识库（合规规则、市场数据），优化AI分析算法，减少误判（如侵权风险、利润测算误差）；
