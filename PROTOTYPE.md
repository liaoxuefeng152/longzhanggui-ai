# 龙掌柜 - 原型设计文档

## 导航结构

### 顶部导航（全局）

```
┌───────────────────────────────────────────────────────────────────┐
│  龙掌柜 Logo      [选品] [上新] [广告] [数据]    [飞书] [设置]  │
└───────────────────────────────────────────────────────────────────┘
```

### 主导航（Tab切换）

- **选品** → 智能选品页面
- **上新** → 快速上新页面
- **广告** → 广告优化页面
- **数据** → 数据概览

| 区域 | 功能 |

## 交互设计规范

### 加载状态
- 按钮显示「加载中...」或「🔄」图标
- 列表显示骨架屏
- 长时间操作显示进度条

### 错误处理
- Toast提示：成功✅、失败❌、警告⚠️
- 表单验证：即时提示错误信息
- 网络错误：提供「重试」按钮

### 空状态
- 友好文案引导操作
- 提供快捷入口按钮
- 举例说明使用场景

### 确认操作
- 删除、发布等危险操作需要二次确认
- 确认弹窗清晰说明后果
- 提供「取消」和「确认」两个选项
